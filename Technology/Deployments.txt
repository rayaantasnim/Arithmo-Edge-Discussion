খ. GitHub Actions দিয়ে অটো-ডিপ্লয়মেন্ট ও ব্যাকএন্ড ক্রন জব ($0/Month)

• Auto-Deploy CI/CD: প্রতিবার তুমি কোড পুশ (git push) করলে GitHub Actions স্বয়ংক্রিয়ভাবে সাইট বিল্ড করে সাথে সাথে লাইভ করে দেবে।
• Scheduled Cron Automation: GitHub Actions-এর ফ্রি শিডিউলার দিয়ে ব্যাকএন্ডের পাইথন স্ক্রিপ্টগুলো চলবে—যা প্রতিদিন নির্দিষ্ট সময়ে অলিম্পিয়াড প্রশ্ন তৈরি ও ১০০% পাইথন স্যান্ডবক্সে যাচাই করবে, ৬ ঘণ্টার হ্যাকিং শেষে রি-জাজ করবে এবং পোস্ট-কনটেস্ট MBTS অ্যান্টি-চিট প্রসেস করে ইলো আপডেট করবে।
• এপিআই কী সুরক্ষা (Zero-Cost Serverless Proxy): যেহেতু GitHub Pages একটি স্ট্যাটিক হোস্ট, তাই তোমার গোপন GEMINI_API_KEY এবং পেমেন্ট ওয়েবহুক লুকিয়ে রাখার জন্য আমরা Cloudflare Workers (*.workers.dev — প্রতিদিন ১,০০,০০০ ফ্রি রিকোয়েস্ট) ব্যবহার করব, যেখানে কোনো কাস্টম ডোমেইন কেনার প্রয়োজনই নেই।
